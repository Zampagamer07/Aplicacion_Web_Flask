Esta plataforma web ha sido creada para facilitar la gestión de reservas de juegos de manera eficiente y simple. Utiliza Flask para su desarrollo y almacena datos en bases de datos SQLite. 

Los usuarios pueden registrarse, iniciar sesión y hacer reservas de juegos, especificando las fechas de reserva y devolución. También incluye un panel de control que permite administrar usuarios, juegos y reservas. Desde este panel, se pueden añadir, modificar o eliminar registros de forma fácil. 

La entrada a la aplicación está asegurada por un sistema de autenticación, y cada función principal se organiza en secciones claras para hacer más sencillo su uso. 

Realizar y manejar reservas (incluyendo fechas de préstamo y de retorno). 

Toda la información se almacena en bases de datos SQLite y está protegida mediante un sistema de sesiones.
